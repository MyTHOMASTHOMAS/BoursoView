# shared

[Retour a l'accueil de la documentation](../README.md)

Le dossier `shared` contient le code commun entre `BoursoViewApi` et `BoursoViewFront`.

Objectif :
- centraliser les types, contrats et elements reutilisables entre le back et le front ;
- garantir une meme structure de donnees des deux cotes.

## Structure

- [RouteType](./RouteType/README.md) : definition des types de routes, requetes et reponses partages.
