# Structure du projet

[Retour a l'accueil de la documentation](./README.md)

Le projet est organise en plusieurs dossiers principaux :

- `BoursoViewApi` : code du backend Google Apps Script.
- `BoursoViewFront` : code de l'application frontend.
- `shared` : code partage entre le frontend et le backend.

Convention importante :
- tout dossier qui commence par `mypkg_` correspond a des librairies externes.
