# Documentation BoursoView

BoursoView est une application de visualisation de donnees boursieres.

Le projet repose sur deux briques principales :
- un backend Google Apps Script qui expose une API et utilise Google Sheets comme base de donnees ;
- un frontend React qui consomme cette API pour afficher les donnees de maniere simple et exploitable.

Ce dossier `docs` centralise la documentation du projet (architecture, fonctionnement, guides et notes techniques).
